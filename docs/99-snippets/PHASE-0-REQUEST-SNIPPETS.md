# CORTE IBÉRICO — Phase 0 Request Snippets

## Access request

> Para arrancar la auditoría con datos reales necesitamos acceso autorizado al Business Portfolio y Ad Account de Meta, o exportaciones oficiales equivalentes. La sesión inicial no requiere hacer cambios en campañas.

## Measurement request

> Necesitamos revisar Events Manager, Pixel y Conversions API, y contrastar esas señales con la fuente independiente donde se registran las ventas. El objetivo es separar señal técnica de realidad económica.

## Scope request

> Antes de convertir observaciones en recomendaciones de ejecución necesitamos cerrar el perímetro: qué entra en auditoría, qué entra en ejecución, quién puede aprobar cambios y qué queda fuera de alcance.

## Christmas request

> Necesitamos fijar el objetivo comercial concreto de Navidad 2026, productos prioritarios, capacidad disponible, presupuesto y condiciones de escalado. Sin estos datos cualquier recomendación de inversión sería prematura.

## Follow-up

> Cuando tengamos estos datos podemos pasar de la pre-auditoría pasiva a un diagnóstico account-level trazable, con cada conclusión vinculada a evidencia.
