# CORTE IBÉRICO — Phase 0 Evidence Request Checklist

## Priority A — Required

- [ ] Meta Business Portfolio identifier
- [ ] Meta Ad Account identifier
- [ ] Authorized account access or equivalent official exports
- [ ] Current users/roles/permissions
- [ ] Current campaign structure
- [ ] Current Pixel configuration
- [ ] Current Conversions API configuration
- [ ] Events Manager diagnostics
- [ ] Independent sales/transaction source
- [ ] Christmas 2026 objective
- [ ] Product availability and operational capacity
- [ ] Audit versus execution scope

## Priority B — Required for diagnosis depth

- [ ] Historical campaign export
- [ ] Historical commercial baseline
- [ ] Catalog/feed state
- [ ] Attribution configuration
- [ ] Checkout/order-flow evidence
- [ ] Refund/cancellation treatment
- [ ] Budget/scaling constraints

## Priority C — Follow-up

- [ ] Creative inventory
- [ ] Audience definitions
- [ ] Landing-page analytics
- [ ] TikTok account/measurement evidence, if in scope
- [ ] Additional channel data

## Evidence handling

Every received artefact must be mapped to:

- EI-* evidence intake identifier;
- relevant CV-* claim, where applicable;
- relevant E-* master evidence record;
- source/date/reference;
- validation state.

Do not promote a screenshot, statement or export to verified evidence merely because it was received.
