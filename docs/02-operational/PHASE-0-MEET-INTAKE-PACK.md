# CORTE IBÉRICO — Phase 0 Meet Intake Pack

## Purpose

Operational pack for the first authorized working session with Corte Ibérico.

The session is an evidence-intake gate, not a diagnosis presentation.

## Session objective

Leave the session with:

1. authorized access or equivalent exports;
2. Meta Business Portfolio and Ad Account identifiers;
3. current campaign structure;
4. Events Manager / Pixel / Conversions API evidence;
5. independent sales baseline and reconciliation path;
6. Christmas 2026 objective and operational constraints;
7. explicit audit-versus-execution scope;
8. named owner for each missing input.

## Operating rule

No account-level conclusion without account-level evidence.

No causal attribution without evidence capable of supporting causality.

## 45-minute agenda

| Time | Block | Output |
|---|---|---|
| 0–5 min | Objective and scope | Agreed Phase 0 boundary |
| 5–15 min | Business Portfolio / Ad Account | IDs, ownership, access |
| 15–25 min | Campaigns / audiences / delivery | Current-state evidence |
| 25–35 min | Pixel / CAPI / Events Manager | Measurement evidence |
| 35–40 min | Ecommerce / sales reconciliation | Source of economic truth |
| 40–45 min | Christmas target / responsibilities | Inputs, owners, next gate |

## Evidence to request

### Meta

- Business Portfolio access or authorized export
- Ad Account ID
- user/role/permission inventory
- campaign/ad set/ad inventory
- objective and optimization configuration
- historical performance export
- Pixel configuration
- Conversions API configuration
- Events Manager diagnostics
- catalog/feed state
- attribution settings where applicable

### Commerce

- ecommerce platform
- checkout/order source
- product/SKU structure
- available transaction export
- refund/cancellation treatment
- stock/capacity constraints

### Business

- Christmas 2026 commercial target
- target period
- product priorities
- operational capacity
- available media budget
- scaling constraints
- historical baseline

## Stop conditions

Stop and register an evidence gap if:

- access is unavailable;
- an account state is described but cannot be inspected;
- a screenshot is presented without enough context;
- a metric has no source definition;
- a sales figure cannot be reconciled;
- a causal explanation is asserted without a controlled basis.

## Expected outcome

Phase 0 closes only when the minimum evidence for the agreed diagnosis exists.

PHASE 1 DIAGNOSIS = BLOCKED remains valid until that gate is satisfied.
