## Important Classification

These documents contain different epistemic levels.

They include:

- project methodology;
- technical perimeter;
- interpretations and hypotheses;
- proposed operating models;
- pre-contractual commercial material;
- contextual screenshots;
- statements that explicitly require later account-level validation.

The existence of a statement inside a project document does not by itself make
that statement an independently verified fact about Meta or Corte Ibérico.

## Source Handling Rule

When a conclusion is derived from one of these documents, the matrix should
reference the corresponding `SRC-*` identifier.

When the document itself identifies an item as a hypothesis, unknown,
inference, proposal or pending validation, the matrix must preserve that state.
