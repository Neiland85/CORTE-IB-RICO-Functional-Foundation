# CORTE IBÉRICO — Master Evidence → Diagnosis → Decision Matrix

## Purpose

This document is the controlled working matrix connecting project evidence,
observed facts, open validation points, technical diagnosis, proposed
solutions, priorities, decisions, and execution.

The matrix must distinguish explicitly between:

- documented evidence;
- observed facts;
- client-provided information;
- working assumptions;
- hypotheses;
- technical diagnosis;
- proposed solutions;
- decisions;
- execution results.

No hypothesis is promoted to fact without supporting evidence.

## Phase Model

### Phase 0 — Evidence Intake & Access

Objective:

Establish the factual baseline before making implementation decisions.

Required outputs:

- source register;
- account/asset inventory;
- access and permission inventory;
- evidence classification;
- credential/security controls;
- known gaps;
- validation queue.

Exit criterion:

The current state can be described without relying on unverified assumptions.

---

### Phase 1 — Current-State Audit

Objective:

Audit the recent operational state and identify measurable causes,
constraints and opportunities relevant to Christmas 2026.

Required outputs:

- campaign audit;
- account/asset configuration findings;
- measurement/tracking findings;
- ecommerce/catalogue findings;
- conversion-path findings;
- evidence-backed diagnosis;
- prioritized remediation list.

Exit criterion:

Each material finding has a supporting source or clearly marked observation.

---

### Phase 2 — Controlled Remediation / Experimentation

Objective:

Implement or test only the changes authorized by the agreed scope.

Required outputs:

- change records;
- experiment definitions;
- baseline metrics;
- observed results;
- rollback criteria;
- decision records.

Exit criterion:

Changes are attributable, measurable and reversible where technically applicable.

---

### Phase 3 — Technical Foundation / Scale

Potential scope:

- ecommerce/web architecture;
- integrations;
- measurement architecture;
- automation;
- catalogue;
- content systems;
- technical governance;
- operational handoff.

This phase must not be assumed to be part of Phase 1 without explicit scope confirmation.

## Evidence Status Vocabulary

- `DOCUMENTED`

- `CLIENT-PROVIDED`
- `VERIFIED`
- `HYPOTHESIS`

`HYPOTHESIS → VERIFIED`

or

`CLIENT-PROVIDED → FACT`

without supporting evidence.
