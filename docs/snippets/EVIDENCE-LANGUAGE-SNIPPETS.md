# CORTE IBÉRICO — Evidence Snippets

Reusable evidence-language snippets for controlled project communication.

## Scope boundary

> The immediate deliverable should be separated from later architecture, ecommerce and integration work. The phase boundary remains subject to explicit client scope confirmation.

**Status:** diagnosis / scope control  
**Do not rewrite as:** confirmed contractual scope.

## Account-level diagnosis gate

> No account-level diagnosis without account-level evidence.

**Status:** governance rule.

## Causal attribution gate

> No causal attribution without evidence capable of supporting causality.

**Status:** governance rule.

## Meta mechanism language

> Undocumented internal Meta mechanisms remain `UNKNOWN / NOT PUBLICLY DOCUMENTED` unless account-level evidence and authoritative documentation establish otherwise.

**Status:** evidence classification rule.

## Security credential state

> Credential creation does not prove continued access; absence of a revocation record does not prove continued activity. Revocation remains open until independently established.

**Status:** security control.

## Evidence status distinction

> `INTEGRITY_CHECKED` establishes repository artifact existence, content integrity or provenance. It does not validate the underlying business or technical claim.

**Status:** evidence-layer rule.
