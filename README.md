# CORTE IBÉRICO — Functional Foundation

Functional foundation for the CORTE IBÉRICO project.

The repository organizes project knowledge and execution around four controlled stages:

1. Evidence
2. Diagnosis
3. Decision
4. Execution

The objective is to preserve traceability between source evidence, technical diagnosis, decisions, and resulting actions.

## Repository Structure

```text
docs/
├── 00-context/
├── 01-evidence/
├── 02-diagnosis/
├── 03-decisions/
├── 04-execution/
└── 05-handoff/

evidence/
decisions/
```

## Working Principle

No material conclusion should be treated as established without identifying its supporting evidence.

No implementation decision should be separated from its diagnosis and rationale.

No execution step should be detached from the decision that authorizes it.

## Scope

This repository is the functional foundation for the project.

Project-specific evidence, decisions, execution records, and controlled handoff documentation belong here according to their respective stage.
